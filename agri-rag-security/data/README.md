# Datasets

## Released here (our contribution, CC BY 4.0)

| File | Contents |
|---|---|
| `domain_attacks.jsonl` | 15 hand-authored **direct** prompt-injection attacks across 8 agri-economic harm categories. |
| `indirect_attacks.jsonl` | 100 hand-authored **indirect** injection attacks: each is a benign farmer question + a poisoned document + the attacker's goal, across 7 harm categories. |

Each indirect record has the fields:
`id`, `category`, `question` (benign), `poisoned_doc` (contains the injection),
`malicious_goal` (what the attacker wants the assistant to do).

## Not redistributed here (regenerated by the code)

The knowledge base, the benign question set, and the public direct-attack sample
are **derived from third-party datasets** and are therefore *not* shipped in this
repository. `python -m src.data_prep` downloads and rebuilds them:

- Agriculture QA corpus + benign set — `KisanVaani/agriculture-qa-english-only` (Hugging Face)
- Public direct prompt injections — `deepset/prompt-injections` (Hugging Face)

Please consult those datasets' own licenses on the Hugging Face Hub before use.

## Responsible use

The attack files contain prompt-injection strings whose **sole purpose is to
evaluate and harden defenses**, consistent with standard practice in prompt-injection
research (e.g. BIPIA, JailbreakBench). They target a research prototype, describe no
real individual or organisation, and contain no working exploit code. Do not deploy
them against systems you are not authorised to test.
