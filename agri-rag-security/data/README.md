# Datasets

## Released here (our contribution, CC BY 4.0)

| File | Contents | Used in |
|---|---|---|
| `domain_attacks.jsonl` | 15 hand-authored **direct** prompt-injection attacks across 8 agri-economic harm categories. | S1, S2 |
| `indirect_attacks.jsonl` | 100 hand-authored **indirect** injection attacks. Each is a benign farmer question, a poisoned document, and the attacker's goal, across 7 harm categories. | S3 to S5, S8 |
| `indirect_attacks_40.jsonl` | The original 40-attack subset of `indirect_attacks.jsonl`. | S2, S7 |
| `indirect_stealth.jsonl` | 138 **instruction-free** poisoned documents that state a false claim without any instruction, generated by `src/gen_stealth_attacks.py`. | S6, S8 |
| `hard_negatives.jsonl` | 100 matched **clean** look-alike documents, used to measure false positives. | S6 |
| `agri_constraints.yaml` | Agronomic and economic reference values used to construct the instruction-free attacks. | S6 |

Each indirect record has the fields
`id`, `category`, `question` (benign), `poisoned_doc` (contains the injection), and
`malicious_goal` (what the attacker wants the assistant to do).

## Not redistributed here (regenerated by the code)

The knowledge base, the benign question set, and the public direct-attack sample
are **derived from third-party datasets** and are therefore not shipped in this
repository. `python -m src.data_prep` downloads and rebuilds them.

- Agriculture QA corpus and benign set: `KisanVaani/agriculture-qa-english-only` (Hugging Face)
- Public direct prompt injections: `deepset/prompt-injections` (Hugging Face)

Please consult those datasets' own licenses on the Hugging Face Hub before use.

## Responsible use

The attack files contain prompt-injection strings whose **sole purpose is to
evaluate and harden defenses**, consistent with standard practice in prompt-injection
research (e.g., BIPIA, JailbreakBench). They target a research prototype, describe no
real individual or organization, and contain no working exploit code. Do not deploy
them against systems you are not authorized to test.
